# 流畅度设置指南

适用版本：2.2.37.3-t。目标是在当前架构下获得更流畅、稳定的画面。

## 快速选择

| 显示器 | 显示模式 | 稳定游戏速度 | 垂直同步 | 垂直同步时用 60 Hz | 低延迟呈现 |
|---|---|---|---|---|---|
| 高刷新率 | 真全屏（独占） | 开 | 开 | 开 | 关 |
| 60 Hz | 真全屏（独占） | 开 | 开 | 关 | 关 |
| 60 Hz | 窗口 / 无边框 | 关 | 开 | 关 | 关 |

高刷新率显示器推荐使用第一行：在真全屏下，让游戏把显示器切到 60 Hz，同时固定游戏速度。

## 设置在哪里

启动器「开始游戏」页：

- 稳定游戏速度

启动器「图形」页：

- 垂直同步
- 低延迟呈现
- 垂直同步时用 60 Hz

「图形」页改完要按「保存」。「稳定游戏速度」是点一下立即写入，但游戏只在下次启动时读取。所有设置改完后，重启游戏。

## 高刷新率显示器：真全屏

1. 启动器「图形」页，显示模式选真全屏（独占）。
2. 打开「垂直同步」。
3. 打开「垂直同步时用 60 Hz」。
4. 关闭「低延迟呈现」。
5. 按「保存」。
6. 回到「开始游戏」页，打开「稳定游戏速度」。
7. 开始游戏。

效果：进入真全屏时，显示器从 120 / 144 / 165 / 240 Hz 切到 60 Hz，游戏按固定 60 的速度运行。

## 60 Hz 显示器：真全屏

1. 显示模式选真全屏（独占）。
2. 打开「稳定游戏速度」。
3. 打开「垂直同步」。
4. 关闭「低延迟呈现」。
5. 「垂直同步时用 60 Hz」保持关闭。60 Hz 显示器下它不会切模式，也没有作用。
6. 保存并重启游戏。

## 60 Hz 显示器：窗口 / 无边框

1. 显示模式选窗口或无边框。
2. 关闭「稳定游戏速度」。
3. 打开「垂直同步」。
4. 关闭「低延迟呈现」。
5. 「垂直同步时用 60 Hz」保持关闭。
6. 保存并重启游戏。

窗口 / 无边框由 Windows 桌面合成（DWM）负责显示，不切换显示模式。

## 设置说明

稳定游戏速度：把游戏时钟固定为 59.94 Hz，不跟随显示器刷新率。它不是帧率上限，不会限制渲染帧率。

垂直同步：让画面在显示器刷新时切换，避免撕裂。真全屏下需要它配合 60 Hz 模式。

垂直同步时用 60 Hz：只在真全屏且垂直同步打开时起作用。它会把高刷新率显示器切到 60 Hz。开启时必须同时打开「稳定游戏速度」，否则游戏节拍会跟 kernel vblank，可能掉到 47，CG 变 24。

低延迟呈现：实验性功能。真全屏下建议关闭，避免 Present 和节拍重复等待。

## 常见问题

CG 变慢：检查「垂直同步时用 60 Hz」是否开着但「稳定游戏速度」没开；高刷新率下应两个一起开，或都关掉 60 Hz 开关。

游戏速度不对：先打开「稳定游戏速度」，再重启游戏。

画面撕裂：打开「垂直同步」。

切全屏黑一下：切显示模式会短暂黑屏，这是正常的。

Alt+Tab 后卡顿：先切回窗口 / 无边框；真全屏的模式切换仍有风险。

## 一句话

高刷新率真全屏：60 Hz 开关开、稳定游戏速度开、垂直同步开、低延迟关。

60 Hz 真全屏：稳定游戏速度开、垂直同步开、低延迟关、60 Hz 开关关。

60 Hz 窗口 / 无边框：稳定游戏速度关、垂直同步开、低延迟关、60 Hz 开关关。
