# 流畅度设置指南

适用版本：2.3.0 起。说明各种显示器和显示模式下画面会是什么样子，以及推荐怎么设置。

## 先说结论

- **游戏速度在任何设置下都正确。** 屏幕刷新率是 60、120、240 Hz 这类（59.94 / 60 / 60.1 Hz 都算）时，游戏时钟对准屏幕的刷新，
  速度和原版的 59.94 Hz 最多差 0.4%（常见的 60.008 Hz 屏幕是 +0.11%）；其他刷新率下时钟固定 59.94 Hz。时钟从不等待屏幕，
  不会出现“CG 变慢”“锁在 24 / 40 帧”这类问题。
- **60 Hz 一类的屏幕：窗口、无边框、真全屏都均匀**，每帧正好显示一次。以前真全屏约每 17 秒一帧多显示一次的问题已经没有了。
- **144 / 165 Hz 屏幕：无边框和真全屏默认切到 60 Hz**，同样每帧显示一次。

## 快速选择

| 显示器 | 推荐显示模式 | 垂直同步 | 全屏时用 60 Hz | 稳定游戏速度 | 低延迟呈现 |
|---|---|---|---|---|---|
| 60 Hz | 任意 | 真全屏：开或关都行（见下） | 无影响 | 关 | 想要更低延迟：真全屏 + 垂直同步下开 |
| 120 / 240 Hz | 任意 | 真全屏：开 | 无影响 | 关 | 无影响 |
| 144 / 165 Hz | 无边框或真全屏 | 真全屏：开 | 开（默认） | 关 | 关 |
| 开了 G-SYNC / FreeSync | 无边框或真全屏，保持默认 | 开或关都行 | 开（默认，最均匀）；想保留高刷就关 | 关 | 关 |

“无影响”表示这一项在该情况下不起作用，开关都一样。

## 各种情况下的画面

### 60 Hz 显示器（包括 59.94 / 60.1 Hz）

- **窗口 / 无边框 / 真全屏 + 垂直同步**：游戏时钟对准屏幕刷新，每帧正好显示一次。
- **真全屏不开垂直同步**：仍会撕裂，但撕裂线被放在刷新的间隙或画面最上、最下的边缘，画面中间基本看不到（实测从约 66% 降到约 0.4%）。
  好处是延迟最低。

### 120 / 240 Hz 显示器

- 游戏时钟每 2 / 4 次刷新走一拍，每帧显示的刷新次数相同。（这一档按设计和仿真推断，作者手上没有这类屏幕实测。）

### 144 / 165 Hz 显示器

60 不能整除 144 / 165，固定刷新下每帧只能在 3 次和 2 次刷新之间交替，有固定的顿挫。

- **无边框 / 真全屏 +「全屏时用 60 Hz」（默认开）**：进入全屏时把这台显示器切到同分辨率的 60 Hz，每帧显示一次。
  无边框最小化、回到窗口或退出游戏时切回原来的刷新率，再显示时又切到 60 Hz。代价：每次切换多黑约 1.5 秒；
  无边框时 Alt+Tab 到别的程序，桌面仍是 60 Hz。真全屏需要打开垂直同步才会切。
- **窗口**：窗口不能单独改屏幕刷新率，仍是 3 次 / 2 次交替。想用窗口又要均匀：在 Windows 显示设置里把刷新率改成 60 Hz。

### 开了 G-SYNC / FreeSync

- **保持默认（全屏切到 60 Hz）**：和 60 Hz 屏幕一样均匀，这是最均匀的选择。
- **关掉「全屏时用 60 Hz」保留高刷**：屏幕跟着游戏的画面刷新。游戏自己每帧画完的时间不一样，程序会把每帧送出的时刻对齐到固定位置
  （多约 5 ms 延迟），让刷新均匀：实测真全屏约 93% 的帧间隔在 16.7 ± 1 ms，无边框约 86%，窗口约 80%。真全屏关掉垂直同步时不这样做（保留最低延迟）。

## 每个设置的作用

- **显示模式**：窗口、无边框全屏、真全屏（独占）。
- **垂直同步**：只在真全屏下起作用。开：不撕裂。关：60 Hz 一类的屏幕上撕裂线被放在画面边缘，延迟最低。窗口和无边框不会撕裂。
- **全屏时用 60 Hz**（以前叫“垂直同步时用 60 Hz”，`black.ini` 里仍是 `exclusive_60hz`）：屏幕是 144 / 165 Hz 这类刷新率时，
  无边框和真全屏（开垂直同步）切到 60 Hz。屏幕本来就是 60 / 120 / 240 Hz 时不切换。它不会改变游戏速度。
- **稳定游戏速度**（「开始游戏」页）：游戏时钟固定 59.94 Hz，任何模式都不对准屏幕。一般保持关闭；只有觉得游戏速度不稳时才打开。
- **低延迟呈现**（实验性）：真全屏并打开垂直同步时，画完的帧如果赶得上下一次刷新就立刻送出，按键到画面送出的延迟从约 16.6 ms 降到 1–5 ms，
  不会多出重复或丢失的帧。窗口和无边框不提前（经过桌面合成时会一帧重复、一帧丢失）；关掉垂直同步时也不提前（会让撕裂线回到画面中间）。
  它不改变游戏速度。
- **Alt+Enter**：依次切换窗口 → 无边框 → 窗口 → 真全屏 → 窗口 …，画面右下角会提示当前模式。退出时记住最后的模式。

## 设置在哪里

- 启动器「开始游戏」页：稳定游戏速度（点一下立即写入）。
- 启动器「显示」页：显示模式。
- 启动器「图形」页：垂直同步、全屏时用 60 Hz、低延迟呈现（改完要按「保存」）。

所有设置在下次启动游戏时生效。

## 常见问题

**画面一顿一顿的**：144 / 165 Hz 屏幕用窗口时最明显，改用无边框或真全屏（保持「全屏时用 60 Hz」打开），或把 Windows 刷新率改成 60 Hz。

**进出全屏黑一下**：「全屏时用 60 Hz」在切换显示模式，约 1.5 秒，正常。不想要可以关掉它（144 / 165 Hz 屏幕会回到 3 次 / 2 次交替）。

**真全屏关垂直同步，转视角时画面边缘有撕裂**：撕裂线被放在画面最上、最下的边缘；完全不想看到就打开垂直同步。

**游戏速度看起来不对**：把 `logs\black.log` 发给作者，日志里 `[clock]` 开头的行记录了时钟在做什么。
