# 流畅度设置指南

适用版本：2.2.37.9 起。说明各种显示器和显示模式下画面会是什么样子，以及推荐怎么设置。

## 先说结论：游戏速度在任何设置下都是正确的

游戏的时钟固定为每秒 59.94 拍，和原版 Xbox 一样，不受显示器刷新率、G-SYNC / FreeSync 影响。
唯一的例外是 **60 Hz 显示器的窗口 / 无边框**：这时游戏时钟跟着 Windows 桌面合成走，画面最均匀，速度相差不到 0.1%。

所以不会出现“CG 变慢”“锁在 24 / 40 帧”这类速度问题。下面各项设置只影响**画面是否均匀、是否撕裂**。

## 快速选择

| 显示器 | 推荐显示模式 | 垂直同步 | 垂直同步时用 60 Hz | 稳定游戏速度 | 低延迟呈现 |
|---|---|---|---|---|---|
| 开了 G-SYNC / FreeSync | 真全屏（独占） | 开或关都可以 | 关 | 关 | 关 |
| 60 Hz | 窗口 / 无边框 | 无影响 | 无影响 | 关 | 关 |
| 120 / 240 Hz | 真全屏（独占） | 开 | 关 | 无影响 | 关 |
| 144 / 165 Hz | 真全屏（独占） | 开 | 开 | 无影响 | 关 |

“无影响”表示这项在该模式下不起作用，开关都一样。

## 各种情况下的画面

### 开了 G-SYNC / FreeSync

- **真全屏**：显卡接管刷新，屏幕跟着游戏的画面刷新，画面均匀、不撕裂。这是最好的组合。
- **窗口 / 无边框**：在一些电脑上 G-SYNC / FreeSync 不会接管（画面由 Windows 桌面合成），效果和没开时一样，见下面对应的刷新率。

### 60 Hz 显示器

- **窗口 / 无边框**：游戏时钟跟着桌面合成，每帧正好显示一次，最均匀。
- **真全屏 + 垂直同步**：游戏时钟 59.94 Hz、屏幕 60 Hz，两者差一点，**大约每 17 秒会有一帧多显示一次**。
- **真全屏不开垂直同步**：画面会横向撕裂。

### 120 / 240 Hz 显示器

- **真全屏 + 垂直同步**：每帧显示 2 / 4 次刷新；同样因为 59.94 和 60 的差别，**120 Hz 大约每 8 秒、240 Hz 大约每 4 秒**有一帧多显示一次刷新。
- **窗口 / 无边框**：画面明显不均匀（不少帧显示 1 次或 3 次刷新）。这是已知问题，正在改进。
  想用窗口 / 无边框又要均匀：在 Windows 的显示设置里把刷新率改成 60 Hz。

### 144 / 165 Hz 显示器

60 不能整除 144 / 165，所以不切换模式时，每帧会在 3 次和 2 次刷新之间交替，有固定的顿挫。

- **真全屏 + 垂直同步 + 「垂直同步时用 60 Hz」**：进入真全屏时把屏幕切到 60 Hz，每帧显示一次，和 60 Hz 真全屏一样（大约每 17 秒一次多显示）。
  代价：进出真全屏（包括 Alt+Tab）要切换显示模式，**每次多黑约 1.5 秒**。
- **窗口 / 无边框**：3 次 / 2 次刷新交替的顿挫。想用窗口又要均匀：把 Windows 的刷新率改成 60 Hz。

## 每个设置的作用

- **显示模式**：窗口、无边框全屏、真全屏（独占）。
- **垂直同步**：只在真全屏下起作用，避免画面撕裂。窗口和无边框本来就不会撕裂。
- **垂直同步时用 60 Hz**：只在真全屏且垂直同步打开时起作用，把屏幕切到 60 Hz。适合 144 / 165 Hz；120 / 240 Hz 开不开差别不大。
  它不会改变游戏速度。
- **稳定游戏速度**（「开始游戏」页）：只影响 **60 Hz 显示器的窗口 / 无边框**，让游戏时钟改用固定的 59.94 Hz、不跟桌面合成。
  一般保持关闭（关闭时更均匀）；只有在这种情况下觉得游戏速度不稳时才打开。其他情况下它不起作用。
- **低延迟呈现**（实验性）：画面画完立刻送出，按键到画面的延迟更低；窗口模式下可能不如关闭时均匀。它不改变游戏速度。
- **Alt+Enter**：在窗口和全屏之间切换。2.2.37.9 起会记住你上次用的是无边框还是真全屏，从窗口切回去时回到那一种。

## 设置在哪里

- 启动器「开始游戏」页：稳定游戏速度（点一下立即写入）。
- 启动器「显示」页：显示模式。
- 启动器「图形」页：垂直同步、垂直同步时用 60 Hz、低延迟呈现（改完要按「保存」）。

所有设置在下次启动游戏时生效。

## 常见问题

**画面一顿一顿的**：先看上面你的显示器对应的说明。120 Hz 以上用窗口 / 无边框时最明显，改用真全屏，或把 Windows 刷新率改成 60 Hz。

**每隔十几秒顿一下**：真全屏开垂直同步时的已知现象（游戏 59.94 Hz 对屏幕 60 Hz）。开了 G-SYNC / FreeSync 时不会有。

**画面撕裂**：真全屏下打开垂直同步。

**进出全屏黑一下**：「垂直同步时用 60 Hz」在切换显示模式，约 1.5 秒，正常。不想要可以关掉它。

**游戏速度看起来不对**：先确认版本是 2.2.37.9 或更新。仍然不对时，把 `logs\black.log` 发给作者。
