# 08 PC 启动器计划（2026-10-22，待用户确认）

## 用户需求（原话整理）

- 选择游戏位置；从镜像安装游戏，装完可以删除镜像。
- 画面设定：16:9、21:9、16:10、4:3；窗口 / 全屏 / 无边框；垂直同步；显示帧率；纹理过滤等。
- 显卡选择；存档管理。
- 键盘设定：按键、手柄。
- 要有忍龙黑之章的图片，一定要好看。
- 原生 Win32 C++；中英双语可切换；取代 run.bat 成为主要入口。

## 设计

- **程序**：`Ninja Gaiden Black Hurricane Launcher.exe`，放在游戏程序旁。原生 Win32，Direct2D + DirectWrite 自绘界面（Windows 自带，无需安装运行环境），DPI 感知。
- **界面**：左侧竖排导航（开始游戏 / 安装 / 画面 / 控制 / 存档 / 关于），右侧内容；深色底配朱红与暗金。背景用从玩家镜像取出的游戏美术（安装后缓存为 PNG，放在启动器旁的 `launcher\art\`，不进仓库、不进发布包）；安装前用纯程序绘制的设计画面，不含任何游戏素材。
- **语言**：简体中文 / English，默认跟随系统，界面上可切换，记在 `launcher.ini`。
- **设定**：启动器只写 `black.ini`（加载器已在读）与 Windows 显卡偏好；新设定先在加载器里实现、可用命令行与 `black.ini` 控制，再接到启动器。
- **启动**：按设定启动游戏程序，启动器可选择留下或关闭。

## 分阶段

1. **骨架与安装**：窗口、导航、双语、`launcher.ini`；选择游戏位置并核对 SHA-256；从镜像安装（XDVDFS 读取，支持 extract-xiso 格式与带视频分区偏移的 redump 镜像，逐文件写出、进度条、完成后核对，再询问是否删除镜像）；安装后从 `spr.afs` 取美术做背景。
2. **画面与显卡**：把加载器已有的设定接上（窗口 / 全屏、窗口大小、渲染分辨率、抗锯齿、16:9 / 4:3、亮度）；显卡：自动（默认独显）/ 独显 / 集显。
3. **存档**：打开存档文件夹、备份 / 还原（带日期的副本）、与 xRevive 存档目录互相导入导出（UDATA / TDATA）。
4. **加载器新功能**（每项先在加载器里做、验证，再进启动器）：
   - 无边框窗口与独占全屏的区分；垂直同步开关；屏幕帧率显示；纹理过滤（各向异性）。
   - 忍龙的键盘 → 手柄映射（键位可改）、手柄按键重映射。
5. **21:9 / 16:10**：需要研究忍龙的投影与视野（Hor+），以及 HUD、过场的处理；风险最大，最后做，做不到的比例在启动器里不开放。

每阶段完成后：自测（截图、日志）→ 用户实机确认 → 提交 → 记入本文件与 docs/07。
