# 12 1.1.9-t：合并 native 并保留 ds-greate 修复

## 来源

- 目标分支：`native-ds-greate`（1.1.8-t，含水下蓝雾 shader 雾因子）
- 合并来源：`native`
  - 远程 `github/native` 的 1.1.9：光晕链修复、固定管线雾因子 1、启动器触控板滚动；
  - 本地 `native` 领先远程的 3 个提交：F9 性能记录、Direct3D 时间不计入引擎帧时间、混合 CPU 性能核选择。
- 合并前已把 `native` 工作树上的未提交改动备份并撤回：
  `work/native_uncommitted_before_merge.patch`（不属于本次发布）。

## 合并后保留

- 1.1.8-t 的水下蓝雾：NV2A 雾因子经 `TEXCOORD4` 进入 `FOGR.a`；
- 1.1.9 的光晕链修复；
- 1.1.9 的固定管线雾因子 1（配合 `FOGR` 的 `c18.w` 标志）；
- F9 性能记录、Load meter、性能核选择。

## 版本

- `project(black_loader VERSION 1.1.9)`；
- `NGB_VERSION_STRING` 改为 `1.1.9-t`，与 ds-greate 发布命名一致；
- 1.1.9 上游发布本身不带 `-t`；本分支按用户要求保留 `-t`。

## 验证

- 合并无文本冲突；`build\ngb2` 构建通过；
- 启动日志：`BLACK loader 1.1.9-t`；
- 启动日志：`cpu: game threads pinned ... performance core`（本机 i5-12500H，CPU 6）；
- 启动日志：`vblank: 59.94 Hz timer`（本分支 1.1.7-t pacing，未合并此前撤销的 QPC 实验）；
- 水面蓝雾沿用 1.1.8-t 的 shader 雾因子路径；
- 光晕、刀光、夜景光柱按 1.1.9 的链修复。

## 未合并

- `native` 工作树的未提交 2D quad snap 改动（已备份，未纳入）；
- 1.1.7-t 之后撤销的 QPC/帧目标实验（不在 ds-greate 基线）。
