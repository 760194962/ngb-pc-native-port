## 关口 3 结论

**通过**：XAPI 初始化 → CRT → 游戏初始化（0x30E090）→ `XInitDevices` → 第一个 D3D 调用 `Direct3D_CreateDevice`，84 ms；没有未实现的内核调用（22 个桩无一命中）、没有异常、没有特权指令命中；fs 改写数 41 = 预期；HANZI 段随整个映像以可读写可执行映射（`image_map` 对整段 `VirtualProtect(PAGE_EXECUTE_READWRITE)`）。

不能由此推出：D3D 之后的内核调用也都已实现（XNET/XONLINE/MU 驱动的 22 个桩尚未被走到）；黑之章的 `CreateDevice` 参数约定（eax = Adapter? ecx = 第 3 参数）要在阶段 4 反汇编核实。
