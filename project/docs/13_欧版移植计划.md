# 13 欧版《忍者龙剑传 黑之章》移植：评估与计划（目标 2.3.0）

对象：`Ninja Gaiden Black (Europe) (En,Fr,De,Es,It).xiso.iso` 的 `default.xbe`（SHA-256 `b61f6eb5fba029aa39a688c6300661c35d69d618afd1c7b6a1573f989480d618`），
测试副本 `recomp2\game\eu\default.xbe`。2026-11-10 评估，全部只读。

## 1. 与美版的关系（证据）

| 项 | 美版 | 欧版 | 说明 |
|---|---|---|---|
| 标题 ID | 5443000d | 5443000d | 同一游戏 |
| 区域 / 版本 | 0x7 / 0x5 | 0x4（欧洲）/ 0x3 | |
| 库版本 | XDK 5849 全套 | 完全相同 | XbSymbolDatabase 两边都识别出 344 个符号 |
| `.text` | 0x369480 | 0x36bb40 | 多 9,920 字节：重新编译，不是补丁版 |
| 库段（D3D、DSOUND…） | | 大小相同，整体后移 0x26C0 | 内容因重定位不同 |
| `.data` | 0x9A433C | 0x9E221C | 多约 250 KB（五国语言文字） |

- 函数顺序完全一致：后移量从 0 单调增长到 +0x26C0，约 40 段，没有重排。同一份源码、局部多出代码（推测为多语言 / PAL）。
- 美版的汉化 / 日文改版都是美版打补丁（地址不变，只加档案）；欧版每个地址都要换算。

## 2. 自动换算能覆盖多少（`tools/x21_map.py` 的 CodeMap，x2.1 → 欧版）

工具：路线 A 反汇编（`work/disasm_EU`）+ XbSymbolDatabase（`work/xbsymbols-EU.txt`）→ `work/functions_EU.csv`（10,570 个函数）。

| 内容 | 结果 |
|---|---|
| 函数配对（指令相同、地址屏蔽、两边唯一） | `.text` 7,827/9,754（80%）、D3D 216/226、DSOUND 317/388、XPP 223/239 |
| HLE 入口（替换函数表） | 105/145 自动；其余 40 个是 DSOUND 的短包装函数（形状相同、配对有歧义），XbSymbolDatabase 按名字都能找到（例：`IDirectSoundBuffer_SetVolume` 欧版 0x37DDA8） |
| 生成的函数清单（`ngb/*_functions.inc`） | 由工具从函数表重新生成，不需手工 |
| 源码里写死的游戏地址（去掉注释、2004 专用文件） | 419 个（代码 399、数据 20）；代码自动对上 278，数据自动对上 3 |

需要人工处理的约 120 个：`dsound.cpp` 39（按名字即可）、`build_profile.h` 39（宽高比常数、HUD 用的返回地址、rdtsc 位置等）、
`ngb_exitmenu.cpp` 12、`timing.cpp` 12、`ngb_livedash.cpp` 8、`resources.cpp` 7、其余约 20（每个文件 1–5 个）；数据地址 17 个。
未配上的多半是局部改过的函数（多语言、PAL），需要对照反汇编逐个确认。清单：`work/eu_eval_unmapped.txt`。

## 3. 计划

1. **地址按版本取用**：现在约 400 个游戏地址直接写在代码里（美版系列共用）。改为"美版地址 → 当前版本地址"的换算表：
   美版及其改版原样返回；欧版查生成的表（`ngb/eu_map.inc`，工具产出 + 人工确认的条目）。查不到的地址在启动时报出，绝不静默用美版地址。
2. **替换函数表**：用现有生成工具按名字 + 配对为欧版产出 D3D / DSOUND / XPP 表。
3. **游戏功能地址**：自动换算的 281 个抽查核对；约 120 个人工对照反汇编确认。
4. **欧版特有**：
   - 50/60 Hz：确认游戏怎样选刷新率，让它按 60 Hz（PAL60）运行；
   - 五国语言：接到启动器现有的"系统语言"；
   - 菜单注入（PC 设置、退出游戏）：多语言菜单结构可能不同，逐项核对；
   - 存档：同一标题 ID，核对美版 / 欧版存档能否互读。
5. **启动器**：识别欧版镜像（哈希）、安装、关于页。
6. **测试**：启动、标题、全部菜单、PC 设置、第一章跑分、过场、存档读写、21:9 HUD、MSAA；美版系列与 2004 回归不变。
7. **发版 2.3.0**（两个仓库）。

风险最高：菜单注入（第 4 项）和 PAL 刷新率；其余以机械工作为主。
